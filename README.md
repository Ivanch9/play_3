# LIGHTSPEED — космический раннер в браузере

3D-раннер на Three.js. Корабль летит вперёд и разгоняется. За 25 секунд он выходит на «скорость света»:
звёзды вытягиваются в цветной тоннель, а небо сжимается вперёд (релятивистская аберрация).
Вместо астероидов и космического мусора появляются чёрные дыры, звёзды и квазары.

## Запуск

```bash
./serve.sh            # http://localhost:8080, слушает только 127.0.0.1
./serve.sh 9000       # другой порт
```

Если игра запущена на удалённом сервере, на своей машине пробросьте порт и откройте браузер:

```bash
ssh -L 8080:localhost:8080 <user>@<server>
# затем открыть http://localhost:8080
```

Сборка, npm и интернет на сервере не нужны: Three.js 0.170.0 лежит в `vendor/`.
Шрифты берутся из Google Fonts. Без интернета у браузера включатся системные шрифты.

## Управление

| Клавиши | Действие |
|---|---|
| `W A S D` / стрелки | манёвр |
| `Пробел` / `Enter` | старт / рестарт |
| `P` / `Esc` | пауза |
| `M` | звук вкл/выкл |

## Игровой процесс

- **0–10 с** — поле астероидов и космический мусор.
- **10–25 с** — поток становится плотнее, астероиды крупнее. Перед световой есть короткое затишье.
- **25 с — скорость света**: вспышка, звуковой удар, тоннель из полос. Дальше скорость растёт как «варп ×N».
- **Чёрные дыры** начинают притягивать корабль заранее, пока подлетают. Можно вырваться, если активно уходить в сторону.
  Касание горизонта событий запускает затягивание со спагеттификацией и закручиванием пространства.
- **Звёзды**: касание короны — корабль сгорает. **Квазары** смертельны ядром и релятивистскими джетами.
- **Маркеры опасности**: пунктирное кольцо или полоса в плоскости корабля показывает смертельную зону объекта, пока он ещё далеко.
- **Близкий пролёт** (меньше 3 единиц от смертельной зоны) даёт +150 очков. Рекорд хранится в `localStorage`.

## Как сделаны объекты

- **Чёрная дыра** — трассировка лучей в шейдере в метрике Шварцшильда: тень (~2.6 r_s), фотонное кольцо,
  аккреционный диск с профилем температуры Шакуры–Сюняева. Дальняя часть диска изогнута линзой над и под тенью.
  Учтены доплеровское усиление и гравитационное красное смещение, фоновые звёзды тоже линзируются.
- **Звезда** — грануляция, пятна с полутенью, потемнение к краю, факелы. Цвет задан излучением чёрного тела
  по спектральному классу (3300–22000 K). Корона с выбросами и протуберанцы.
- **Квазар** — сверхъяркое ядро, горячий диск с доплером, два джета с бегущими «узлами» и ореол галактики-хозяина.
- **Астероиды** — процедурная геометрия: шум и кратеры с валами. Мусор — панели, баки, фермы с мигающими маячками.
- **Постобработка** — bloom, радиальное размытие скорости, хроматическая аберрация, тряска камеры при разгоне,
  линза и закрутка при падении в дыру.
- **Звук** — синтезируется через Web Audio API, файлов нет.

## Отладочные параметры URL

| Параметр | Что делает |
|---|---|
| `?debug=1` | FPS, pixel ratio и время раунда |
| `?t=24` | старт с указанной секунды (например, сразу перед световой) |
| `?god=1` | неуязвимость |
| `?autostart=1` | старт без нажатия пробела |
| `?demo=blackhole` / `star` / `quasar` | объект перед кораблём, мир стоит — можно рассмотреть |
| `?demo=blackhole&suck=1` | сразу показать затягивание в дыру |

Пример: `http://localhost:8080/?t=24&god=1&debug=1`

Если FPS падает ниже 45, игра автоматически снижает разрешение рендера.

## Тюнинг

Все параметры баланса собраны в `js/config.js`: время до световой, скорости, сила гравитации, размеры коридора и бонусы.

## Структура

```
index.html, css/style.css
js/main.js          игровой цикл, состояния, камера, HUD
js/config.js        баланс
js/spawner.js       спавн по фазам, коллизии, гравитация
js/markers.js       маркеры опасных зон
js/ship.js          процедурный корабль и факелы двигателей
js/starfield.js     звёзды и варп-полосы
js/sky.js           небо: туманности и релятивистская аберрация
js/fx.js            постобработка
js/audio.js         синтезированный звук
js/explosion.js     частицы взрыва
js/glsl.js          общий GLSL (шум, чёрное тело)
js/obstacles/       asteroid.js, blackhole.js, star.js, quasar.js
vendor/three/       Three.js 0.170.0 (MIT)
```
